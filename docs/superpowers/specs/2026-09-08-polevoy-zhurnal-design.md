# Полевой журнал — спецификация

Дата: 2026-09-08  
Платформа: Ren'Py 8.5 (SDK уже есть у автора: `C:\Users\User\renpy-8.5.3-sdk`)  
Корень проекта: `C:\Users\User\Documents\polevoy-zhurnal`

## Зачем

Короткий ритуал на 15–25 минут, который передаёт воздух песен и записей Романа Евгеньевича Сидорова (Fatal, Der Golem, Sedativ, Старуха Мха), не копируя тексты, мелодии и биографию.

Дуга, которую несёт игра: человек → руины цивилизации → возвращение в лес.

## Что не делаем

- Не цитируем и не переписываем чужие тексты песен.
- Не кладём в игру записи Сидорова и чужой музыки.
- Не показываем гибель, петлю, способы ухода. Финал — только то, что стало с записью.
- Не делаем биографическую игру «про Романа». Герой — безымянный, кто пишет звук.
- Нет инвентаря, карты, боёв, галереи, гарема, сохранений как геймплея. Стандартные Save/Load Ren'Py оставляем в меню паузы, в самом ритуале не подчёркиваем.

## Форма

Одна линейная ночь из трёх актов («кассет»).  
Игрок — тот, кто пишет полевую сессию: магнитофон, ночь, место само решает, что ляжет на плёнку.

Два промежуточных выбора (кассеты I и II) меняют *окраску* плёнки.  
Один последний жест (кассета III) выбирает один из трёх финалов.

## Сюжет

### Кассета I — Подвал

Переоборудованная точка. Лампа на одной частоте, капля из батареи, гитара, которую не забрали. Человеческий слой ещё держится: шаги, дыхание, голос в наушниках, который звучит чужим.

Выбор:

- **Записать голос** → `voice_kept = True`
- **Стереть. Оставить гул** → `voice_kept = False`

Если голос оставлен, дальше мир чуть человечнее. Если стёрт — дыра не зарастает.

### Кассета II — Завод

Ночная полевая сессия в руинах. Металл, сквозняк в цехе, петля удара по баку. Цивилизация слышна как пустая оболочка.

Выбор:

- **Идти за шумом, в траву** → `followed_noise = True` (выход за проходную, к траве)
- **Остаться. Писать смерть вещей** → `followed_noise = False`

### Кассета III — Лес

Папоротник, мох, вода, деревья, которые стоят слишком внимательно. Микрофон пишет то, чего не было в ушах. Текст третьего акта учитывает `voice_kept` и `followed_noise` (см. окраску ниже).

Последний жест — финал:

1. **Забрать кассету** → финал «Кассета»
2. **Стереть всё** → финал «Сквозняк»
3. **Оставить магнитофон в мху** → финал «Мох»

## Окраска плёнки

Кассеты I и II не меняют, *какой* финал доступен. Они меняют формулировки в III и в концовке.

| `voice_kept` | `followed_noise` | Ощущение плёнки |
|---|---|---|
| True | False | Человек среди железа. Голос держится, вещи пустые. |
| True | True | Человек, который уже слышит траву. |
| False | False | Только гул и вещи. Дыра вместо голоса. |
| False | True | Голоса нет. Шум сам ушёл в траву. |

Явно: все четыре комбинации допустимы. Финал «Кассета» / «Сквозняк» / «Мох» доступен в каждой.

Окраска в тексте:

- Если `voice_kept`: в лесу один раз возвращается собственный голос в наушниках, уже неузнаваемый.
- Если не `voice_kept`: в лесу дыра на месте голоса; пишется только то, что не человек.
- Если `followed_noise`: завод в III вспоминается как уже пройденный порог; трава началась раньше леса.
- Если не `followed_noise`: лес приходит сразу после железа, без переходной травы; вещи ещё слышны в мхе.

## Финалы

### Кассета

Игрок уносит запись домой. Экран: тихая комната не нужна — достаточно счётчика, который останавливается, REC гаснет.

- Если `voice_kept`: дома это почти человек. Чужой голос в наушниках, который когда-то был твоим.
- Если не `voice_kept`: дома это просто шум. Можно сказать другим, что там был лес. Не услышат.

### Сквозняк

Плёнка пустая. Вещи говорили без людей. Короткий чёрный кадр, сквозняк, счётчик обнуляется.

### Мох

Магнитофон остаётся. Лес дописывает сам. Игрок уходит без прибора. Счётчик продолжает идти уже без «тебя» в кадре: REC горит, текст кончается.

Ни в одном финале нет сцены смерти персонажа.

## Интерфейс

Экран — прибор, не классическая новелла.

- Разрешение: 1280×720.
- Нет имени героя, нет namebox.
- Сверху слева: `КАССЕТА I · ПОДВАЛ` / `II · ЗАВОД` / `III · ЛЕС`. В финале подпись меняется на имя финала (`КАССЕТА` / `СКВОЗНЯК` / `МОХ`).
- Сверху справа: красный `● REC` и счётчик `MM:SS:FF` (минуты:секунды:кадры, кадры 00–23). Счётчик идёт, пока идёт сцена. На финале «Кассета» REC гаснет и счётчик замирает. На «Сквозняк» счётчик сбрасывается в нули. На «Мох» REC остаётся, счётчик идёт.
- Текст реплик — нижняя треть, без рамки-«окошка» по умолчанию; лёгкий градиент снизу, чтобы читать.
- Выборы — две (в III — три) центрированные строки-кнопки в стиле магнитофона: тонкая рамка, моноширинный шрифт, без подсветки-акварели Ren'Py.
- Главное меню: чёрный/янтарный фон, название «Полевой журнал», пункты Начать / Продолжить / Выход. Без яркого дефолтного GUI.

Шрифт: DejaVu Sans из поставки Ren'Py, увеличенный межбуквенный интервал — чтобы читался как подпись на приборе, без отдельных файлов шрифтов.

## Картинка

Один визуальный язык, три палитры (вариант A, согласован):

- Подвал — янтарь лампы, зерно, тёмное дерево/бетон.
- Завод — ржавчина, холодный металл, сквозняк в кадре.
- Лес — мох, мало зелени, больше тьмы между стволами.

Мало цвета, много зерна. Не «красивый концепт-арт», а полевой кадр. Фоновые изображения: три основных + по необходимости один переходный (проходная/трава) и чёрный для сквозняка. Без спрайтов персонажей.

## Звук

Только оригинальные петли, сделанные для игры:

- `hum_basement` — лампа, низкий гул, редкая капля.
- `factory_wind` — сквозняк, металл.
- `forest_moss` — вода/листва, обработанные до неузнаваемости, не «библиотека птичек».
- Короткий щелчок магнитофона на старте записи и на жестах «записать / стереть».

Петель мало, они тихие, без мелодии. Пользователь может позже положить свои файлы в `game/audio/` — имена петель фиксируем в коде, чтобы замена была простой.

## Данные

Переменные (default в `script.rpy`):

- `voice_kept` — bool, по умолчанию True до выбора, выставляется в I.
- `followed_noise` — bool, по умолчанию False до выбора, выставляется в II.
- `ending` — `"cassette"` / `"wind"` / `"moss"`, выставляется в III.

Нет инвентаря. Нет очков. Нет скрытых проверок сверх окраски текста.

История читается сверху вниз в одном `script.rpy`. HUD живёт в `screens.rpy`, чтобы текст истории не смешивался с разметкой прибора.

## Запуск

Проект открывается в Ren'Py SDK 8.5 как отдельная игра. После первой сборки — `Полевой журнал` в списке проектов (имя в `options.rpy`: `Полевой журнал`).

## Проверка

Проходить вручную:

1. Все три финала достижимы с дефолтных промежуточных выборов.
2. Четыре комбинации I×II реально меняют хотя бы одну фразу в III и хотя бы одну фразу выбранного финала.
3. HUD: подпись кассеты верная; REC и счётчик ведут себя по правилам финалов.
4. Главное меню на русском, игра стартует в подвале, выход не падает.
5. Нет цитат чужих песен и нет сцен гибели.

Автотестов Ren'Py не требуется: объём маленький, проверка — прогон lint (`renpy.exe polevoy-zhurnal lint`) и три ручных прохода финалов.
