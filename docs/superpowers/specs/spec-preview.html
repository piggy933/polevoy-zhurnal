Полевой журнал — спецификация

2026-09-08 · Ren'Py 8.5 · C:\Users\User\Documents\polevoy-zhurnal

Зачем

Короткий ритуал на 15–25 минут, который передаёт воздух песен и записей Романа Евгеньевича Сидорова (Fatal, Der Golem, Sedativ, Старуха Мха), не копируя тексты, мелодии и биографию.

Дуга: человек → руины цивилизации → возвращение в лес.

Что не делаем

  • Не цитируем и не переписываем чужие тексты песен.
  • Не кладём в игру записи Сидорова и чужой музыки.
  • Не показываем гибель, петлю, способы ухода. Финал — только то, что стало с записью.
  • Не делаем биографическую игру «про Романа». Герой — безымянный, кто пишет звук.
  • Нет инвентаря, карты, боёв. Save/Load остаются в меню паузы, в ритуале не подчёркиваем.

Форма

Одна линейная ночь из трёх актов («кассет»). Игрок пишет полевую сессию.

Два промежуточных выбора (I и II) меняют окраску плёнки. Последний жест (III) выбирает один из трёх финалов.

Сюжет

Кассета I — Подвал

Лампа, капля, гитара, которую не забрали. Человеческий слой ещё держится.

  • Записать голос → voice_kept = True
  • Стереть. Оставить гул → voice_kept = False

Кассета II — Завод

Ночь в руинах. Сквозняк, петля удара по баку.

  • Идти за шумом, в траву → followed_noise = True
  • Остаться. Писать смерть вещей → followed_noise = False

Кассета III — Лес

Папоротник, мох, деревья, которые стоят слишком внимательно.

  1. Забрать кассету → финал «Кассета»
  2. Стереть всё → финал «Сквозняк»
  3. Оставить магнитофон в мху → финал «Мох»

Окраска плёнки

I и II не меняют, какой финал доступен. Меняют формулировки в III и в концовке.

voice_keptfollowed_noiseОщущение
TrueFalseЧеловек среди железа. Голос держится, вещи пустые.
TrueTrueЧеловек, который уже слышит траву.
FalseFalseТолько гул и вещи. Дыра вместо голоса.
FalseTrueГолоса нет. Шум сам ушёл в траву.

Финалы

Кассета

Уносишь запись. REC гаснет, счётчик замирает. Если голос оставлен — дома это почти человек. Если стёрт — просто шум.

Сквозняк

Плёнка пустая. Чёрный кадр, счётчик в нули.

Мох

Магнитофон остаётся. Лес дописывает сам. REC горит, счётчик идёт без тебя в кадре.

Ни в одном финале нет сцены смерти персонажа.

Интерфейс

  • 1280×720, экран — прибор, без namebox.
  • Слева: КАССЕТА I · ПОДВАЛ (и дальше). В финале — имя финала.
  • Справа: красный ● REC и счётчик MM:SS:FF.
  • Текст в нижней трети. Выборы — тонкие кнопки записи.
  • Меню: Полевой журнал — Начать / Продолжить / Выход.

Картинка и звук

Янтарь подвала → ржавчина завода → мох леса. Мало цвета, много зерна. Без спрайтов.

Свои петли: hum_basement, factory_wind, forest_moss, щелчок магнитофона. Не песни Сидорова.

Проверка

  1. Три финала достижимы.
  2. Четыре комбинации I×II меняют текст в III и в финале.
  3. HUD ведёт себя по правилам финалов.
  4. Меню на русском, старт в подвале.
  5. Нет чужих цитат и сцен гибели.
